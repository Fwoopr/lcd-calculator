# LCD Calculator

An interactive, Arduino-based calculator that uses the Serial Monitor for user input and a 16x2 I2C LCD screen for real-time prompts and results.

---

## Demo

![Demo GIF](demo.gif)

---

## How It Works

The program waits for input via the Serial Monitor (num1, op, num2). It than calculates the answer using the given numbers and operators. All prompts and the final answer are displayed on a 16x2 LCD screen using IC2 protocol.

---

## Components
- Arduino Uno
- 1x 16x2 LCD Screen
- Jumper Wires
